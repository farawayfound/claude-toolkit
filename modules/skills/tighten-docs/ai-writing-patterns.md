# AI-writing patterns

Flag each hit with file:line, then rewrite as a plain statement of fact. A doc that reads like a person wrote it has short sentences, concrete nouns and no sales language.

| Pattern | Example | Fix |
|---|---|---|
| Selling adjectives | robust, seamless, comprehensive, powerful, elegant, cutting-edge | delete the adjective or state the measurable fact |
| Triads and lists of three for rhythm | "fast, safe and simple" | keep the one that is true and checkable |
| Hedge stacks | "It is worth noting that this may potentially" | say it or cut it |
| Signposting | "In summary", "Overall", "Importantly", "Let's dive in" | delete the phrase |
| Contrast frames | "This is not X, it is Y" | state Y |
| Rhetorical questions | "Why does this matter?" | state the answer |
| Bold lead-ins on every bullet | **Safety:** ... **Speed:** ... | plain bullets, or a table with real columns |
| Emoji and badges as headings | rocket, check mark, sparkle | plain headings |
| "ensures that", "leverages", "utilizes", "facilitates" | "This ensures that data is validated" | "Validates the data", with where and how |
| Colon-label sentences | "Result: a faster path." | a sentence with a verb |
| Uniform sentence length | every sentence 18 words | vary; one short sentence after a long one |
| Em-dash chains | A thing — another thing — a third | full stops or commas |
| Restating the heading | under "Tests": "This section describes the tests" | start with the content |
| Passive attribution | "It was decided that" | "I chose X because Y" |
| Future-tense promises | "will be added in a future version" | "Not done: X. Next step: Y" |
| Generic closers | "Feel free to reach out", "Happy coding" | delete |
| Reviewer flattery or rubric talk | "as a reviewer will appreciate" | delete the sentence |
| Over-qualified claims | "arguably one of the most" | the claim, or nothing |

Two prompts for the sections the user writes: *Decisions*: "Name three calls you made against the agent's suggestion and why." *AI use*: "What did the tool write, what did you verify by hand, and what did you change?"
